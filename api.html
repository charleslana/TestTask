Escrita de envio/recebimento de objetos para API, você deve seguir conforme os detalhes abaixo:

$ - o sinal de $(dólar) é utilizado para envio/recebimento de arrays na estrutura do root [Ex: $]

. - o sinal de .(ponto) é utilizado para envio/recebimento de objetos na estrutura do root [Ex: .foo]

data.foo - o sinal de data.foo(ponto depois de um objeto) é utilizado para envio/recebimento de objetos aninhados [Ex: data.foo]

data[0].foo - o sinal de data[0].foo(objeto com array com pós objeto) é utilizado para envio/recebimento de objetos que possua uma lista com objetos [Ex: data[0].foo]
